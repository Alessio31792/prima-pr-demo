# Prima PR Demo

Repository di prova per imparare a creare una Pull Request su GitHub.

## Cosa fa questo progetto

Niente di particolare: è un repository vuoto usato solo per fare pratica con il flusso di lavoro di Git e GitHub (branch, commit, pull request).
